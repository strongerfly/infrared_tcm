## 阶段含义

各轨道内部按这个顺序推进。可以暂停，跳步要在日志里写原因。

| 阶段 | 完成时看得到什么 |
| --- | --- |
| 0 范围 | 研究问题与 LIMITS 自查一致 |
| 1 器件与波段摘录 | NIR 与 LWIR（或书面放弃其中之一的理由）有出处、日期、摘录位置 |
| 2 指标与词表 | 成功标准里的操作定义和 `region_id` 冻结 |
| 3 采集方案 | 仓库外数据的字段、标准源步骤、人体数据的伦理前置条件 |
| 4 算法笔记 | 每个列入的算法族有用途、失败现象、是否继续 |
| 5 重复性数值 | 仅当测量发生之后填写；空缺保持为空 |
| 6 融合 | 只读 [fusion/README.md](fusion/README.md) 的前提；未满足则保持未开始 |

阶段 5 可以长期为空。空不是失败。

## 更新规则

1. 改了轨道文档里的研究问题、词表或成功标准，同步改总览的“当前焦点”和日期。
2. 摘录器件规格时写出处。规格数字不进总览，除非附上笔记路径。
3. 人体影像不进仓库。进度板只写“仓库外会话已采集”这类事实，不写身份。
4. 外部论文的诊断或疗效句子不记为本项目结果。
5. 融合行在四轨都到达阶段 2 之前保持 `未开始`。
