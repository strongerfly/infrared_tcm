# 手部轨道（Hand）

手部掌侧与背侧外表面的红外成像质量与空间分布。本轨道独立于面、舌、耳。掌侧与背侧分成两个视图，不在未配准的情况下混算。结论边界见 [../../LIMITS.md](../../LIMITS.md)。

## 研究问题

1. 非接触采集时，手掌摊平的姿态残差（手指分开程度、腕部旋转）会让分区统计变化多少？
2. 从不同室温进入后，表观温度分布随时间怎么变？协议里的等待时间应以哪一次标准源加体模或以后的重复测量来确定？
3. 接触窗口或托架若被考虑，压力与接触热传导会在 LWIR 上留下什么可检测伪影？非接触是否应作为默认？
4. NIR 图像中浅表血管形成的线状对比，作为成像结构有多稳定？它是否干扰掌面分区的反射统计，从而需要单独的掩膜？
5. 指甲、戒指、汗液与掌纹深谷的阴影，哪些应排除出皮肤分区统计？
6. 手指分区像素少时，统计应升到整指，还是保留指节？判据是边界误差相对分区面积的比例。

浅表血管对比不用于身份识别，也不用于推断血管疾病。掌纹只作为可能的阴影来源。

## 候选波段与传感器

| 候选 | 大致范围 | 调研时要回答的问题 |
| --- | --- | --- |
| NIR | 约 700–1000 nm；比较 850 nm 与 940 nm | 透射照明与反射照明哪一种更适合非接触；血管对比与掌面反射如何分离 |
| SWIR | 约 1.0–1.7 μm | 水分（汗）是否造成大面积镜面或吸收，使分区不可比 |
| LWIR | 约 8–14 μm | 适应环境的时间尺度、手指与掌心的空间采样、接触伪影 |
| VIS | 约 400–700 nm | 辅助手指分开的关键点与指甲掩膜 |

传感器调研维度：

- 视场要同时放下手掌与手指，或协议规定手指收入的裁切方式
- 照明均匀性：手是立体的，指缝阴影明显
- 热像仪测温范围是否覆盖室温下手表，以及自动增益是否锁死
- 托架的材料发射率与导热，若默认非接触则记为“不采用”及原因

手背与手掌的角质层厚度和血管可见性不同。两侧视图的波段优先级可以不同，但要各自写理由，不共用一套未经测量的参数。

## 待调研的算法族

| 算法族 | 在本轨道的用途 | 调研时排除的用法 |
| --- | --- | --- |
| 手部关键点与姿态 | 判断手指分开、掌面正对相机、腕部入画 | 手势语义、身份 |
| 皮肤 / 指甲 / 背景分割 | 统计只在皮肤掩膜上进行 | 皮损检测终点 |
| 掌侧与背侧视图分类 | 防止两侧混入同一次统计 | 由视图推断检查项目 |
| 血管状结构掩膜（NIR） | 把线状高对比从分区反射统计中分开或单独描述其覆盖率 | 生物特征模板、血管疾病判定 |
| 辐射定标与时间曲线 | 记录适应阶段的漂移，选取进入稳定段的帧 | 把稳定段温度解释成循环功能 |
| 接触伪影检测 | 若评估过接触方案，检测边缘热印 | 默认不启用接触采集 |
| 分区统计 | 掌心、大鱼际、小鱼际、手指等几何区的分位数 | 证候、疾病或风险分 |
| 质量门控 | 出画、并指、运动、汗液饱和、定标过期 | 用质量分表示手部“状态好坏” |

调研顺序：姿态与皮肤掩膜，然后 NIR 上是否需要血管掩膜，再是 LWIR 的时间稳定段。两侧视图分开写实验，避免一帧里掌背同时出现却无法标注。

## 数据需求

当前无数据集。

**对象顺序**

1. 标准源、漫反射板、简单手形体模：均匀性、阴影、距离。不做生物样品。
2. 人体手部：伦理与去标识满足 [../../LIMITS.md](../../LIMITS.md) 后，影像放在仓库外。默认非接触。

**每个会话至少记录**

- 假名、会话号、时间、轨道=`hand`
- 视图=`palmar` 或 `dorsal`；侧别=`left` 或 `right`
- 波段、照明几何（反射或透射）、距离、环境温度、进入房间后的等待秒数
- 发射率设定、增益锁定、是否佩戴戒指（应在协议中要求摘除，并记录例外）
- 仓库外 URI：帧、皮肤掩膜、指甲掩膜、可选的血管状掩膜、分区图

**方案里单列的干扰**

- 进入采集环境前的气温差异、洗手后残留水
- 手指并拢、手掌未摊平
- 汗液与掌纹阴影
- NIR 血管对比过强导致分区均值跟着血管覆盖率走

## 成功标准

1. 研究问题 1–6 具备操作定义。姿态问题要具体到可标注项：五指是否分开、掌面法向与相机夹角的估计方式。
2. 视图与侧别进入主键。掌侧与背侧的分区词表分开。掌侧起步建议：`palm_center`、`thenar`、`hypothenar`、`digit_1`…`digit_5`。背侧用对应的背面标识，不与掌侧混用同一统计池。
3. 默认采集为非接触。若笔记讨论接触窗口，必须同时写下伪影检测方法与“默认关闭”的结论位置。
4. NIR 与 LWIR 各有一条带来源的器件或照明摘录。血管状掩膜是否纳入，由一份短笔记决定：覆盖率变化对分区中位数的影响是否超过重复测量散差。该比较待测。
5. 重复性终点：稳定段内分区中位数的短时重复散差；稳定段的起点由时间曲线规则定义，而不是由肉眼挑帧。
6. 质量旗标最少包括：出画、并指、运动模糊、指甲未剔除、汗液饱和、增益变化、定标过期、视图侧别缺失。
7. 对照 LIMITS，无诊断、辨证、疗效、身份识别或临床风险分。

阈值与散差在测量前保持空缺。
