# 耳部轨道（Ear）

耳廓外表面的红外成像质量与空间分布。本轨道独立于面、舌、手。观察范围是耳廓外侧可见皮肤，不含耳道内。结论边界见 [../../LIMITS.md](../../LIMITS.md)。

耳廓面积小、曲面起伏大、容易被头发挡住。本轨道的主要困难是像素数量与遮挡，不是耳穴图谱。

## 研究问题

1. 在固定工作距离下，耳廓在探测器上占多少像素时，分区统计的离散程度才主要由重复采集决定，而不是由分割边界的一两个像素决定？
2. 头发、耳饰、口罩系带与侧脸姿态，怎样系统性地吃掉耳轮或耳垂的有效像素？
3. 耳廓曲面相对相机的倾角变化时，LWIR 表观温度与 NIR 反射谁对角度更敏感？
4. 左右耳分开采集时，什么配准基准（耳屏、对耳轮、耳垂）能让几何分区在重复拍摄中对齐？
5. 环境辐射在耳廓凹凸处的反射，是否大到使耳甲艇一类凹陷分区不可比？
6. 质量门控如何处理“耳廓不完整”：整耳作废，还是仅废弃被挡分区？

耳穴名称与治疗点不进入分区词表。解剖词用于定位曲面，不表示刺激或诊疗位点。

## 候选波段与传感器

| 候选 | 大致范围 | 调研时要回答的问题 |
| --- | --- | --- |
| NIR | 约 700–1000 nm | 侧向照明下的阴影是否比生理对比更大；毛发在近红外是否仍强遮挡 |
| SWIR | 约 1.0–1.7 μm | 小靶面相机的分辨率是否够耳廓分区 |
| LWIR | 约 8–14 μm | 微测辐射热计在小视场、近距离下的空间分辨率与最小对焦；凹面处的环境反射 |
| MWIR | 约 3–5 μm | 仅当 LWIR 空间分辨率不足时再评估器件代价 |
| VIS | 约 400–700 nm | 辅助描出耳廓外轮廓与毛发遮挡 |

传感器调研维度：

- 空间采样：耳廓高度方向的像素数，镜头最近对焦距离，景深是否盖住耳轮到耳甲
- 左右耳采集是移动相机还是双相机；时间差是否要记入热漂移
- 背景：头发与衣领的温度或反射是否侵入掩膜
- 输出是否允许关闭自动增益，以便重复比较

耳廓薄、两侧空气交换强。表观温度受环境与时间影响的幅度需要在方案里单独测量，不沿用面部的适应时间假设。

## 待调研的算法族

| 算法族 | 在本轨道的用途 | 调研时排除的用法 |
| --- | --- | --- |
| 耳廓检测 | 在侧脸或局部画面中框出单耳 | 身份识别 |
| 外轮廓与解剖关键点 | 耳轮、对耳轮、耳屏、耳垂，服务几何分区 | 耳穴检测、刺激点推荐 |
| 遮挡分割 | 头发、饰品、手指与耳廓皮肤分开 | 把遮挡区插值成“完整耳图”后继续统计 |
| 曲面姿态估计 | 记录倾角，解释角度引起的亮度或表观温度梯度 | 三维重建本身不作为本阶段终点 |
| 左右耳分别配准 | 各耳自己的重复采集对齐 | 把左右耳叠到一张图上求病理不对称 |
| 辐射定标 | 同热成像链路的标准源校正，加记近距离对焦失败 | 由耳温推核心温度 |
| 分区统计 | 仅在未遮挡像素上计算分位数，并报告有效像素比例 | 耳穴能量、证候或疾病分类 |
| 质量门控 | 出画、对焦失败、遮挡超限、增益自动变化 | 以完整性评分暗示健康程度 |

凹陷分区若环境反射无法校正，成功标准允许将该分区标为“本阶段不统计”，并写明判据。

## 数据需求

当前无数据集。

**对象顺序**

1. 物理耳廓模型或曲面体模加标准源，测量像素采样、景深与角度。不涉及生物材料制备。
2. 人体耳廓：伦理与去标识条件满足后再采集，文件放在仓库外。左右耳都记，允许单耳因遮挡无效。

**每个会话至少记录**

- 假名、会话号、时间、轨道=`ear`、侧别=`left` 或 `right`
- 波段、距离、镜头、环境温度、发射率设定、增益是否锁定
- 头发是否拨开、耳饰是否摘除（采集条件，不是评分）
- 仓库外 URI：帧、耳廓掩膜、遮挡掩膜、分区图

**方案里单列**

- 长发、短发、耳道口不可见（耳道内不拍）
- 从不同环境进入后的等待时间
- 单耳像素数下限：低于下限则整耳质量失败

## 成功标准

1. 研究问题都有操作定义。其中像素采样问题要写成：耳廓外接矩形高度的像素数，以及分区统计对边界腐蚀 1 像素的敏感度。
2. 几何词表起步建议：`helix`、`antihelix`、`tragus`、`lobule`、`concha`。`concha` 允许在反射评估后被标成不统计。词表不含耳穴编号。
3. 侧别是主键的一部分。左右比较若被定义，只作为两侧分区统计的差值，并同时报告各自有效像素比例与倾角。
4. LWIR 近距离可行性有书面结论草稿结构：对焦距离、耳廓像素数、是否锁定增益。数值待测。
5. 分割终点：耳廓皮肤掩膜 IoU，以及头发误入比例。
6. 质量旗标最少包括：出画、失焦、遮挡超限、自动增益、定标过期、像素数不足。
7. 对照 LIMITS，无耳穴诊疗、诊断、疗效或身份识别表述。

未测的分辨率与重复性保持空缺。
