# 舌部轨道（Tongue）

伸舌时舌体外表面的红外成像质量与空间分布。本轨道独立于面、耳、手。分区是几何位置。结论边界见 [../../LIMITS.md](../../LIMITS.md)。

舌面湿、反光强、可停留时间短。算法调研围绕这三件事，而不是围绕苔色或舌质的传统判读。

## 研究问题

1. 一次伸舌里，可用的稳定帧窗口有多长？运动模糊与舌体回缩怎样被自动标成无效？
2. 唾液造成的镜面高光在 NIR，以及气流与湿表面在 LWIR，会把分区统计偏移到什么程度？偏移能否用偏振、照明角度或帧选择压低？
3. 舌体与唇、齿、口腔背景的分割，在红外帧上是否可靠；可见光帧若只做分割辅助，配准误差上限是多少？
4. 几何分区（舌尖、舌边、舌中、舌根可见部分）在重复伸舌之间能否对齐到可比较的像素比例？
5. 表面液体厚度变化时，哪些分布特征是照明/热交换伪影，哪些在短时重复里仍然保留？
6. 质量门控能否在统计之前去掉未完全伸舌、卷舌、牙齿遮挡过半的帧？

经典文献把舌尖、舌边、舌中、舌根与脏腑对应。本轨道的同名分区**只表示几何区域**。笔记使用这些名字时保持几何定义，不继承脏腑或证候映射。

## 候选波段与传感器

| 候选 | 大致范围 | 调研时要回答的问题 |
| --- | --- | --- |
| NIR | 约 700–1000 nm；比较 850 nm 与 940 nm | 水与镜面反射是否主导；窄带照明加偏振能否留下稳定的表面对比 |
| SWIR | 约 1.0–1.7 μm | 水吸收是否使舌面大面积饱和或失去分区对比 |
| LWIR | 约 8–14 μm | 伸舌后表观温度随秒级时间下降的幅度；口腔气流与环境反射 |
| VIS | 约 400–700 nm | 仅辅助舌体分割与几何分区；不把颜色写成苔色或舌质判定 |

传感器与光学调研维度：

- 工作距离与视场：舌体充满画面且唇齿仍可分开
- 曝光与帧率：覆盖伸舌开始后的短时间序列，而不是单张快照
- 照明：偏振方向、入射角、是否泄漏到可见光而改变受试者配合（仅作为采集干扰记录）
- LWIR：发射率设定、镜头近距离的最小对焦、呼气气流
- 卫生：非接触优先。若将来讨论接触式窗口，只记成像伪影与清洁流程对光学的影响，不记临床操作规范

湿表面的发射率与干燥皮肤不同。未核对测量文献前，不把面部轨道的发射率设定抄到舌部。

## 待调研的算法族

| 算法族 | 在本轨道的用途 | 调研时排除的用法 |
| --- | --- | --- |
| 舌体分割 | 从唇、齿、背景中分出舌体掩膜 | 以分割结果推断苔的厚薄等级 |
| 关键点与中线 | 舌尖、两侧缘、可见舌根边界，建立几何分区 | 脏腑分区模板 |
| 短时序列选择 | 在一次伸舌中选取运动最小、覆盖足够的帧 | 把时间曲线解释成功能变化 |
| 高光与饱和检测 | 标记唾液镜面像素并排除出统计 | 把高光区域当成独立“证” |
| 辐射或反射定标 | 同面部轨道的标准源思路，另加近距离湿表面的已知困难 | 反演含水量的临床数值 |
| 纹理描述 | 在有效像素上记录空间频率或局部方差，服务重复性 | 苔质、裂纹的诊断分类 |
| 分布统计 | 几何分区的分位数与有效像素比例 | 证候或疾病分类 |
| 质量门控 | 未伸全、卷曲、齿遮挡、模糊、超时 | 用质量分评价“舌象好坏” |

算法顺序：先分割与帧选择，再高光掩膜，再讨论分区统计是否可重复。纹理特征在分区重复性有定义之后再调研。

## 数据需求

当前无数据集。

**对象顺序**

1. 体模：湿润与干燥的漫反射样品、已知反射率板，观察高光与距离。不使用生物样本培养物。
2. 人体伸舌图像：伦理、知情同意与去标识满足 [../../LIMITS.md](../../LIMITS.md) 之后，数据留在仓库外。

**每个会话至少记录**

- 假名、会话号、时间、轨道=`tongue`
- 波段、照明与偏振配置、距离、帧率
- 伸舌口令的计时：从张口到选中帧的时间戳
- 是否见齿、是否卷舌（操作者旗标，属采集质量，不是舌象评分）
- 环境温度、热像仪发射率设定
- 仓库外 URI：序列、选中帧、舌体掩膜、高光掩膜、分区图

**需要在方案里单列的干扰**

- 伸舌时长、重复次数造成的疲劳与唾液变化
- 饮料、进食与采集的时间间隔（作为待控制变量，不解释成饮食疗法）
- 舌面反光导致的分区有效像素比例过低

## 成功标准

1. 六条研究问题都有操作定义，包括“有效帧”的判定顺序：分割成功 → 运动低于阈值 → 有效像素比例足够 → 高光比例可接受。阈值本身待测。
2. 几何词表固定，建议起步：`tip`、`margin_l`、`margin_r`、`center`、`root_visible`。每个标识附一句几何边界（相对舌尖点与中线），并写明不承载脏腑含义。
3. NIR 与 LWIR（若 LWIR 近距离无法对焦，则明确写失败条件）各有手册或文献摘录；VIS 的角色限定为分割辅助。
4. 重复性终点定义在**有效像素**上：同一人短时两次伸舌的分区中位数差，以及有效像素比例。
5. 分割终点定义：舌体掩膜相对人工描边的 IoU，以及齿/唇误入比例。
6. 质量旗标最少包括：模糊、未伸全、卷舌、齿遮挡、高光过多、超时、定标过期。
7. 对照 LIMITS 自查，无苔色诊断、辨证、疗效或临床决策表述。

指标数值在测量前保持空缺。
