# 面部轨道（Face）

面部外表面的红外成像质量与空间分布。本轨道独立于舌、耳、手。分区是几何位置。结论边界见 [../../LIMITS.md](../../LIMITS.md)。

## 研究问题

1. 在写明的距离、角度与环境条件下，长波红外（LWIR）面部表观温度图与近红外（NIR）反射图，重复采集时分区统计能稳定到什么程度？
2. 环境热辐射在 LWIR 面部图像里的反射贡献、以及 NIR 主动照明的不均匀，各自怎样进入分区均值与分位数？
3. 表情、说话、眼镜、毛发、妆容和汗液，哪些会破坏关键点、掩膜或辐射测量，从而应当触发质量门控？
4. 额、眶周、颊、鼻、颏、唇作为几何分区，掩膜一致性（不同操作者或不同算法）达到什么水平才够用来比较分布？
5. 左右差分位数是否适合作为**描述统计**？该指标的操作定义是什么，它对姿态残差有多敏感？
6. 质量指标（模糊、饱和、覆盖率、漂移）能否在看分布统计之前筛掉不可比的帧？

本轨道不把左右差、局部冷热或反射模式映射到证候或疾病。

## 候选波段与传感器

调研时按波段填写数据手册与文献来源。下表是候选范围，不是已选配置。

| 候选 | 大致范围 | 调研时要回答的问题 |
| --- | --- | --- |
| NIR | 约 700–1000 nm；照明中心常比较 850 nm 与 940 nm | 主动照明均匀性、皮肤色调对信号的影响、浅表结构对比是否稳定 |
| SWIR | 约 1.0–1.7 μm（常见 InGaAs）；更长波段另列 | 水分与表面反射是否淹没分区差异；成本与分辨率是否值得单独立项 |
| MWIR | 约 3–5 μm | 与 LWIR 相比，反射与器件成本是否改变重复性结论 |
| LWIR | 约 8–14 μm | 非制冷微测辐射热计的非均匀性、漂移、发射率设定与表观温度重复性 |
| VIS | 约 400–700 nm | 仅用于与红外帧配准、估计姿态与遮挡；不作为色诊 |

传感器调研维度（数值留待手册）：

- 像元数、像元尺寸、帧率、镜头视场与工作距离
- LWIR：NETD 的定义条件、测温档、非均匀性校正（NUC）是否对用户开放、输出是辐射温度还是原始电平
- NIR：量子效率曲线、是否有环境光抑制、照明的几何（环光、偏振）
- 时间同步：可见光与红外是否需要硬件触发
- 输出接口与辐射定标流程（黑体、面源、积分球等标准源）

文献里皮肤在 LWIR 的发射率常被取为接近 1 的常数。写入笔记前核对原始测量条件（部位、波段、含水）。未核对前，发射率只作为仪器设定项，不作为组织真值。

## 待调研的算法族

每族只记录要解决的成像问题、公开方法类别、失败时的可见现象。实现留到有数据字典之后。

| 算法族 | 在本轨道的用途 | 调研时排除的用法 |
| --- | --- | --- |
| 人脸检测与关键点 | 摆正、估计姿态、生成几何分区初值 | 身份识别；表情的情绪或健康解释 |
| 语义分割 / 掩膜 | 皮肤区域与眼镜、毛发、背景分离 | 皮损检测作为终点 |
| 分区模板与非刚性配准 | 把重复采集映射到同一几何分区 | 跨人“标准面”上的临床对照 |
| 辐射定标与漂移校正 | 黑体或面源把电平连到表观温度；记录环境温度 | 把表观温度写成核心温度或血流 |
| NIR 平场与光照模型 | 分离照明不均匀与表面反射 | 由反射反推色素或血红蛋白浓度（除非另立并核对的光学模型笔记） |
| 空间分布统计 | 分区均值、标准差、分位数、梯度、左右差 | 疾病或证候分类器 |
| 质量门控 | 模糊、运动、饱和、遮挡、出画、测温漂移 | 用质量分代替分布报告 |
| 无监督分组 | 发现采集失败模式或协议簇 | 以疾病标签做监督 |

优先顺序建议写在进度板里：先质量门控与分区掩膜，再辐射重复性，再左右差一类派生统计。

## 数据需求

当前无数据集。需求是以后采集方案必须满足的字段与约束。

**对象顺序**

1. 标准源与体模：均匀面源、黑体、漫反射板，用于链路重复性，不涉及人体。
2. 人体面部：仅在 [../../LIMITS.md](../../LIMITS.md) 的伦理与去标识前置条件满足之后。

**每个会话至少记录**

- 假名、会话号、时间、轨道=`face`
- 波段、中心波长与带宽、传感器与镜头标识、工作距离
- 环境温度、仪器发射率设定、NUC 或平场文件标识、照明标识
- 姿态说明：正面或规定偏角；是否摘除眼镜
- 仓库外的原始帧、掩膜、表观温度或反射图 URI
- 质量旗标

**多样性与干扰（写入方案，避免样本只覆盖一种条件）**

- 肤色、胡须、刘海、妆容、汗液、环境空调、采集前是否从不同室温进入
- 重复：同一条件短时重拍，以及隔日重拍，用来定义短期与隔日重复性

原始帧不进 git。

## 成功标准

本轨道在文档阶段即视为达标，当下列各项都写进笔记并且能被他人执行核对：

1. 研究问题 1–6 各有对应指标的**操作定义**（公式或步骤级描述、单位、在哪一掩膜上计算）。
2. 候选波段表中，NIR 与 LWIR 至少各有一条来自手册或论文的摘录，并带出处与日期；SWIR/MWIR 标明“继续调研”或“本阶段不展开”及理由。
3. 几何分区词表固定为一组标识（建议起步：`forehead`、`periocular`、`cheek_l`、`cheek_r`、`nose`、`chin`、`lips`），并说明唇与眶周可以因妆容或眼镜整区作废。
4. 重复性终点被定义：例如分区中位数的短时重复标准差，或同类组内相关。阈值待测，不预先写成已达到。
5. 掩膜一致性终点被定义：操作者之间或算法与操作者之间的交并比（IoU）。
6. 质量门控列出最少旗标：模糊、饱和、关键结构出画、运动、定标过期。
7. 全文对照 LIMITS 自查表，无诊断、辨证、疗效、认证与临床决策表述。

未采集数据时，成功标准 4 与 5 的状态是“指标已定义、数值空缺”。空缺保持可见，不填推测数字。
