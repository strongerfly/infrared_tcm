# 红外成像与算法研究笔记（Infrared Imaging Research Notes）

本仓库记录**红外成像质量**与**空间分布算法**的调研笔记。观察部位取自中医文献里常被描述的体表：面、舌、耳、手。四条轨道分开推进。把多轨分布放在一起做可视化，属于更后的阶段。

这些笔记研究的是图像怎么采、怎么量、分布怎么描述。它们不构成诊断、辨证、疗效判断、器械认证或临床决策支持。边界见 [docs/LIMITS.md](docs/LIMITS.md)。

## 北极星（North star）

在各自轨道内，把下列三件事写清楚，并保持可复核：

1. **采集链路**：波段、传感器、照明或热环境、几何与辐射误差从哪里来。
2. **分布描述**：在几何分区上，表观温度、反射或同类物理量的空间分布如何表示、如何比较重复采集。
3. **算法边界**：每一类算法解决的是检测、分割、配准、定标、质量门控还是分布统计；输出停在成像与描述。

四条轨道互不代替。一条轨道的分区词表、误差源和成功标准不自动套到另一条。

## 边界（Limits）

## 文档约定

- 正文默认简体中文。标题可带短英文。
- 物理量使用可核对的名称：表观温度、辐射、反射率、分区像素统计。未核对出处的数值不写进结论。
- 分区名称表示几何位置（如颊、舌尖、耳垂、掌心），词表由各轨道自己维护。
- 人体影像、可识别元数据与原始身份不进入本仓库。数据字典只描述仓库外存储应具备的字段。
- 本目录是研究笔记，不是应用代码。
